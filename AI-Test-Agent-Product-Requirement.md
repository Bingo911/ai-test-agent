版本：V1.0

状态：Draft

日期：2026-09

------------------------------------------------------------------------

# 1. 产品概述

## 1.1 产品名称

AI Test Agent

## 1.2 产品定位

AI Test Agent 是一个基于人工智能的 Web 自动化测试平台。

用户通过 Markdown
格式描述测试场景，系统将测试描述转换为标准化测试模型（Test
IR），并调用浏览器自动化执行引擎完成测试。

系统支持：

-   AI测试理解
-   智能元素定位
-   自动化执行
-   测试结果分析
-   人工协助

------------------------------------------------------------------------

# 2. 产品目标

## 2.1 核心目标

降低 Web 自动化测试开发成本。

传统模式：

测试人员 → 编写代码 → 维护 Selector → 执行测试

AI模式：

测试人员 → 编写测试描述 → AI解析 → 自动执行

------------------------------------------------------------------------

# 3. 产品范围

## 3.1 V1支持范围

Web UI 自动化测试。

支持：

执行能力：

-   输入
-   清空
-   上传文件
-   页面等待
-   页面断言
-   截图

------------------------------------------------------------------------

## 3.2 V1不支持

暂不支持：

-   移动端 App 测试
-   API 测试
-   自动探索测试
-   绕过验证码

# 5. 核心功能需求

## 5.1 测试用例管理

支持：

-   Markdown上传
-   在线编辑
-   版本管理
-   标签管理

------------------------------------------------------------------------

## 5.2 Markdown测试DSL

示例：

``` md
# 登录测试

## Step 1

action: open

url:
https://example.com/login

## Step 2

action: input

target:
  description: 用户名输入框
  type: input

value:
admin

## Step 3

action: click

target:
  description: 登录按钮
  type: button

## Step 4

action: assert

condition:
page_contains:
欢迎回来
```

------------------------------------------------------------------------

## 5.3 AI测试解析

输入：

Markdown

输出：

Test IR

要求：

-   保留原始描述
-   输出结构化动作
-   支持错误提示

------------------------------------------------------------------------

## 5.4 自动化执行

执行引擎：

Playwright

支持：

-   浏览器启动
-   页面操作
-   状态检测
-   日志记录

------------------------------------------------------------------------

## 5.5 智能定位

元素定位优先级：

1.  CSS Selector
2.  Accessibility Role
3.  Text
4.  XPath
5.  AI视觉

------------------------------------------------------------------------

## 5.6 自动失败分析

失败时收集：

-   Screenshot
-   DOM
-   Console Log
-   Network
-   Trace

AI生成：

-   失败原因
-   建议方案

------------------------------------------------------------------------

## 5.7 人工协助

支持人工接管。

场景：

-   验证码
-   OTP
-   人工确认

流程：

自动暂停

↓

保存浏览器 Session

↓

人工处理

↓

继续执行
